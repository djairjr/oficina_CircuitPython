## Full Neopixel Console Code
Os códigos para todos os jogos dessa pasta foramm os utilizados nas primeiras oficinas de Circuitpython, que foi realizada no **Sesc Santana e no Sesc 24 de Maio em 2024**.
Naquela ocasião, tive que adaptar a versão da Adafruit_Pixelbuffer, para utlizar duas telas 32x8 criando um display 32x16. Mais tarde, aprendi a  fazer isso usando a biblioteca nativa da Adafruit e a oficina de 2025 no **Sesc da Avenida Paulista** já seguiu esse caminho.

Os jogos Snake, Maze, Arkanoid, Space Invaders e Tetris foram criados como classes. Os códigos estavam ainda bem bugados, com problemas que foram corrigidos nas versões posteriores.

Mantive os arquivos e a pasta no repositório apenas para demonstrar a criação de uma camada de abstração para lidar com o hardware.

Confira os arquivos **code.py** e **hardware.py** para ver como criei um sistema de menu e toda a inicialização do hardware.
